□ 3D MAZE GENERATOR by Marco Carnegie
02 / ABOUT

Why was this project made?

I made this project to helpbuild my algorithm creating skills and to try make a project in 3D.

How does it work?

It works by generating a perfect maze using a randomied recursive backtracking algorithm and then sends that result to a threeJS program to render the maze and a charecter that you can control. You can explore the maze in first person and view your position in the maze from a birds eye view. It also renders the maze as one large mesh that allows for much faster generation of larger mazes

01 Algorithm Recursive Backtracking
02 Renderer three.js, WebGL, one draw call for the maze
03 Guarantee Exactly one path between any two cells. No loops, no islands.
